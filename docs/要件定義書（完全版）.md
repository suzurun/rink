### **【1. システム概要】**

| 項目 | 内容 |
| ----- | ----- |
| システム名 | 不動産建築会社向け 施工情報管理システム |
| 開発目的 | 物件情報・図面・PDF・画像・動画の一元管理、外出先から閲覧可能にする |
| 主利用端末 | iPad・スマホ・PC（社内 PC で登録 / iPad で閲覧） |
| 利用ユーザー数 | 社内 30 名、外部 5 名、将来最大 100 名 |
| 登録物件数 | 初期 100 件 → 将来 1,000 件規模 |
| 登録ファイル | 1物件あたり最大 30 ファイル（画像/PDF/動画/図面） |
| 保存容量 | 初期 20GB → 100GB 以上へスケール可能 |

---

### **【2. ユーザー種別と権限】**

| ユーザー種別 | できること | できないこと |
| ----- | ----- | ----- |
| admin | 全権限、ユーザー管理、物件CRUD、削除、外部権限管理 | なし |
| internal（社内ユーザー） | 物件閲覧、登録、編集、アップロード | ユーザー管理、削除 |
| external（外部業者） | ✕ 物件閲覧不可（セキュリティのため） | すべての物件閲覧・検索 |

### **【4. 非機能要件】**

| 区分 | 内容 |
| ----- | ----- |
| 可用性 | AWSサーバーレス（DynamoDB / Lambda）で安定稼働 |
| セキュリティ | S3は private、署名付きURLのみアクセス可 |
| 認証 | Cognito（メール \+ PW）、外部ユーザー閲覧不可 |
| パフォーマンス | 検索は DynamoDB GSI で高速化 |
| スケール | 物件 1,000件、ファイル 3万点まで対応 |
| 費用 | 月額 1万〜2万円を目標（S3/CloudFront中心） |
