# **画面仕様書（UI/UX仕様） Ver.1.0】**

AWSサーバーレスシステム｜iPad・スマホ最適化

---

# **\======================================**

# **1\. 画面一覧 & 画面ID**

# **\======================================**

| 画面ID | 名称 | 想定デバイス | 権限 |
| ----- | ----- | ----- | ----- |
| G01 | ログイン画面 | PC / iPad / スマホ | 全ユーザー |
| G02 | ダッシュボード（物件一覧） | PC / iPad | internal/admin |
| G03 | 地図ビュー（MapView） | iPad / スマホ | internal/admin |
| G04 | 物件詳細 | PC / iPad | internal/admin |
| G05 | ファイル一覧（物件詳細内タブ） | PC / iPad | internal/admin |
| G06 | 物件登録（新規登録） | PCのみ | internal/admin |
| G07 | 物件編集 | PCのみ | internal/admin |
| G08 | 一括登録（Excel/CSV） | PCのみ | admin |
| G09 | ユーザー管理 | PC / iPad | admin |
| G10 | 権限エラー画面 | 全デバイス | external |

---

# **\======================================**

# **2\. 画面遷移図**

# **\======================================**

`G01 ログイン`  
   `↓ 認証成功`  
   `→ G02 物件一覧`  
       `↓ 物件選択`  
       `→ G04 物件詳細`  
           `↓ タブ切替`  
           `→ G05 ファイル一覧`  
       `↓ 地図ボタン`  
       `→ G03 地図ビュー`  
   `↓ 一括登録（管理者）`  
   `→ G08 一括登録画面`  
   `↓ ユーザー管理（管理者）`  
   `→ G09 ユーザー管理`

external ユーザーは：

`G01 → ログイン → G10 権限エラー → 閲覧不可`

# **\======================================**

# **3\. 各画面仕様**

# **\======================================**

---

# **🟦 G01：ログイン画面**

### **要素**

* メールアドレス入力欄

* パスワード入力欄

* 「ログイン」ボタン

* 「パスワードを忘れた方はこちら」リンク

### **挙動**

* Cognito 認証

* external はログインできるが、物件一覧に遷移した時点で 403 → G10 へ

### **UI（ワイヤーフレーム）**

`+-------------------------+`  
`|   ログイン             |`  
`| [メールアドレス]       |`  
`| [パスワード      ]     |`  
`| [ ログインボタン ]     |`  
`| パスワード再設定       |`  
`+-------------------------+`

---

# **🟦 G02：物件一覧（ホーム画面）**

### **要素**

* 検索バー（キーワード／住所／担当者）

* 絞り込み：

  * 大項目・中項目・小項目

  * 用途地域

  * 構造

  * 引渡時期

* 並び順：最新順／名称順

* 一覧：カードビュー（iPad向け）

* 地図ビューへ切替ボタン

* 新規登録（PCのみ表示）

### **UIワイヤー**

`[検索ボックス]  [絞り込みボタン]`

`----------------------------------`  
`| 物件カード                     |`  
`| ・物件名                       |`  
`| ・住所                         |`  
`| ・大項目 / 中項目 / 小項目     |`  
`| ・担当者                       |`  
`----------------------------------`

`[前へ]  1 2 3 4  [次へ]`

---

# **🟦 G03：地図ビュー（MapView）**

### **要素**

* Google Maps

* ピン：物件位置

* ピンタップでポップアップ

* ポップアップから → 物件詳細へ遷移

### **UIワイヤー**

`[検索条件保持したまま]`

  `+--------------------------+`  
  `|         地図表示         |`  
  `|        (GoogleMap)       |`  
  `|   📍物件A                 |`  
  `|   📍物件B                 |`  
  `+--------------------------+`

---

# **🟦 G04：物件詳細**

### **要素**

* 基本情報（読み取り専用）

* 編集ボタン（PCのみ）

* ファイルタブ

* 地図ボタンクリックで位置確認

* 表示項目（例）

  * 物件名称

  * 所在地

  * 緯度経度

  * 地目

  * 用途地域

  * 構造

  * 種類（大中小）

  * 面積

  * 引渡時期

  * 担当者

  * メモ

### **UIワイヤー**

`[物件名]`  
`住所：福岡市…`  
`地図で表示`  
`--------------------------`  
`[基本情報] [ファイル] ← タブ`  
`--------------------------`

---

# **🟦 G05：ファイル一覧（物件詳細内タブ）**

### **タブ構造**

* 写真（photo）

* 図面（drawing）

* PDF（pdf）

* 動画（movie）

* その他（other）

### **表示仕様**

* 各フォルダ内 → ファイル名あいうえお順

* 種類順で表示（タブは種類順に並ぶ）

### **UIワイヤー**

`[写真] [図面] [PDF] [動画] [その他]`

`----------------------------------------`  
`| [サムネイル]  [サムネイル] [サムネイル]`  
`|  filenameA     filenameB     ...`  
`----------------------------------------`

---

# **🟦 G06：物件登録（PC限定）**

### **要素**

* ExcelテンプレートDLボタン

* 入力項目（現行そのまま）

* 必須項目：物件名／住所／大項目など

* 地図検索（住所 → 緯度経度自動取得）

### **UIワイヤー**

`[物件登録フォーム]`  
`物件ID: __________`  
`物件名: __________`  
`住所:  __________`  
`[地図検索ボタン]`

`(以降：現行項目すべて)`

---

# **🟦 G08：一括登録 Excel/CSV（管理者）**

### **要素**

* テンプレートダウンロード

* ファイルアップロード

* 成功件数／失敗件数のサマリ

* エラー行のCSVダウンロード

### **UIワイヤー**

`[テンプレートダウンロード]`

`[ファイル選択] [アップロード]`

`登録成功：120件`    
`エラー：5件（CSVダウンロード）`

# **📘 Excelテンプレート項目仕様（正式版）**

# **\===============================**

| 列名 | 必須 | 型 | 説明 |
| ----- | ----- | ----- | ----- |
| propertyId | ○ | string | 主キー |
| name | ○ | string | 物件名 |
| zipcode | ○ | string | 郵便番号 |
| prefecture | ○ | string | 都道府県 |
| city | ○ | string | 市区町村 |
| address | ○ | string | 番地 |
| lat | 任意 | number | 緯度 |
| lng | 任意 | number | 経度 |
| typeLarge | ○ | string | 大項目 |
| typeMedium | 任意 | string | 中項目 |
| typeSmall | 任意 | string | 小項目 |
| landUse | 任意 | string | 用途地域 |
| structure | 任意 | string | 構造（木造など） |
| area | 任意 | number | 面積 |
| owner | 任意 | string | 施主 |
| staff | 任意 | string | 担当者 |
| deliveryDate | 任意 | YYYYMMDD | 引渡時期 |
| memo | 任意 | string | 備考 |
